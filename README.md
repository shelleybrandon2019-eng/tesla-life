# Tesla Lease Tracker

A phone-friendly Model Y lease checklist covering delivery, mileage, care and records, and lease return.

## How it works

Open `index.html` directly or use the GitHub Pages site. Checkbox progress, lease details, mileage check-ins, and service/damage notes are stored locally in the browser. Use **Download backup** to save a copy of the tracker data.

## GitHub Pages

The included workflow publishes the root of the `main` branch to GitHub Pages after each push. If Pages is not already enabled, open **Settings → Pages** in the repository and choose **GitHub Actions** as the source, then run the workflow.
